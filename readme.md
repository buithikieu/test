# THACO Industries Chatbot Platform
- Chatbot Platform is a platform that allows users to create their own chatbot, serving purposes such as sales consulting, customer care support, service instructions, order receiving, etc. ..
- The project focuses on technology to deploy software systems in the form of containerized applications, using container orchestration technology with Kubernetes
  

## Technology


### Django Rest Framework (Platform BE)
  + Authentication with JWT (Bearer)
  + Caching with Redis Server (Not Implemented)
  + Asynchronous Deployment with Gunicorn & Uvicorn

### React (Platform FE)
  + Ant Design UI Components
    
### Postgres (Platform DB)
  + High availablity Master Slave Replication Database (3 replicas)
    
### PgAdmin (Manage DB with UI)
  
### RASA (Chatbot BE)
  + Rasa Core
  + Rasa Actions
  + Rasa Duckling
  + Rasa API
  + Rasa Tracker Store

### Docker (Build Images & CI Server)
  + Multi Stages Build
  + Non-Root User
  + Jenkins CICD Server

### Kubernetes (Deploy & CD Server)
  + Helm charts
  + Longhorn Storage
  + ArgoCD Server
  + Prometheus & Grafana Dashboard
